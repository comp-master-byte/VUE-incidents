# Дашборд инцидентов

Проект на Vue 3: очередь инцидентов с фильтрами, деталями, созданием/удалением и страницей аналитики.

Цель архитектуры — **слабая связанность модулей**: экраны, доменные данные и UI-kit разделены, чтобы проще добавлять и убирать части приложения.

## Стек

- Vue 3 + TypeScript + Vite
- Vue Router
- Pinia
- vee-validate + yup
- ECharts (`vue-echarts`)
- ESLint + Oxlint + Prettier

## Возможности

### Дашборд (`/`)

- список инцидентов с поиском, фильтром по статусу и сортировкой
- панель деталей выбранного инцидента
- смена статуса (optimistic update)
- создание и удаление инцидентов
- данные в `localStorage` (мок API)

### Аналитика (`/analytics`)

- сводные карточки (всего / открытые / critical / решены)
- распределение по статусам и приоритетам
- топ сервисов
- последние critical / high

## Быстрый старт

Требуется Node.js `^22.18` или `>=24.12`.

```bash
npm install
npm run dev
```

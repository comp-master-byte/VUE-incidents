## Архитектура

Используется модульная архитектура. Проект разделён на слои по ответственности.

### `core`

Сборка приложения: `App`, роутер, глобальная инициализация, провайдеры.

### `modules`

Страницы и сценарии UI.
Здесь лежит код, который нужен конкретному экрану: page-компоненты, локальные сторы, фильтры, выбранные элементы, view-state.

Примеры:

- `modules/incidents-dashboard` — дашборд: поиск, сортировка, выбранный инцидент
- `modules/incidents-analytics` — аналитика: агрегации и графики по инцидентам

### `features`

Переиспользуемая доменная логика.
Здесь лежит код, который нужен нескольким модулям: сторы данных, сервисы, API-маппинг.

Пример: `features/incidents` хранит общий список инцидентов и операции над ним (CRUD, загрузка).

### `shared`

Общий код без бизнес-сценария: UI-компоненты, типы, константы, утилиты.
`shared` не зависит от `features` и `modules`.

## Правила импортов

```text
core     → modules, features, shared
modules  → features, shared
features → shared
shared   → external libs
```
